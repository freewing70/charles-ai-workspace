AI 公司先被 AI 改變：Anthropic 初級招募只剩 9%

Anthropic 週五發布自家實測報告：到今年 8 月，員工指揮的 AI agent 工時已達人類的 6 倍，而技術部門初級員工佔比從 21% 掉到 14%、初級招募佔比更從 27% 跌到 9%。

報告由 Anthropic Institute 研究員 Nathan Wilmers 等人執筆、10 月 16 日發布，基於內部僱用、工時、AI 用量資料與 17 位員工訪談。Agent 總工時在 3 月首度超過人類總工時；工程師每人程式碼提交量達半年前的 5 倍，且 agent 寫的程式碼被退回的比例與人類親手寫的一樣。

法律部門合約處理量、銷售成交數同步上升；非技術員工使用 coding agent 的次數從每月 2 次爆增到 90 次；員工花在「監控 agent 管線」的元工作佔比從 10% 升到 22%，開會時間多了 20%。公司認為自家職場可能是整體經濟的領先指標。

為什麼重要： 這是前沿 AI 實驗室第一次把「AI 取代初級職位」量化攤在陽光下——它回答了市場最怕的問題：agent 革命的第一批犧牲者，是新鮮人。

Claude 半小時破解 NSA 埋了 25 年的密碼學之謎

Anthropic 週四宣布，內部 Claude 研究模型只花不到半小時，就解開了困擾密碼學界 25 年的謎團：NSA 提供給 NIST 橢圓曲線標準的「種子」到底從哪來。

五條 NIST 曲線（P-192、P-224、P-256、P-384、P-521）的種子，來自老 C 語言函式庫的 lrand48 偽隨機數產生器，以 Unix 時間戳做種子；P-256 的種子是 1997 年 8 月 16 日那次運行產生的第 1842 個候選值。長期以來的陰謀論認為這些數字可能是英文短語的雜湊、藏著 NSA 後門；Claude 的發現讓「刻意留後門」的可能性大降。

研究由 10 人團隊領軍，2023 年懸賞的 3.6 萬美元獎金將捐給 ISRG。不過仍有部分曲線參數的來源尚未解開。

為什麼重要： 這不只是密碼學八卦——它證明了前沿模型已能做「真正的科學發現」：在無人指引方向的情況下，從原始數據裡挖出人類 25 年沒找到的統計指紋。

駭客把 AI API key 當提款機：OpenCode 遭「蒸餾攻擊」

熱門開源 AI 編碼工具 OpenCode 背後的 Anomaly Innovations 週六坦承：駭客攻入即將退役的舊版 Console 系統，約 1.4% 用戶存在工作區的 OpenAI、Anthropic、Google API key 可能外洩。

公司把這波攻擊稱為「大規模蒸餾攻擊」——駭客目標不是密碼或付款資料，而是拿偷來的 key 大量呼叫高階模型，把運算成本轉嫁到受害者帳上，疑似用來蒸餾訓練自己的便宜模型。已有多名開發者回報帳單異常：有人被盜刷數百美元 Anthropic 費用、有人 Google 專案被停權。

公司在 10 月 17 日晚間 22:51 UTC 才發出第一封通知信，距離最早可確認的曝光時間點晚了約 22 小時；詳細時間軸甚至是外部開發者先拼出來的。公司正與三家模型商合作善後，呼籲用戶立刻撤銷並重發 key。

為什麼重要： AI API key 現在就是信用卡——這起事件把「把 key 交給第三方工具」的風險血淋淋攤開，也讓「蒸餾」這條灰色產業鏈第一次有了受害者現身說法。

死對頭牽手：Samsung 找台積電 3 奈米幫 Nvidia 造記憶體

路透 10 月 18 日引述《首爾經濟日報》報導：Samsung Electronics 將採用台積電 3 奈米製程，為 Nvidia 下一代客製化高頻寬記憶體 NVHBM 生產 base die——這是三星史上第一次在 HBM 製造階段與台積電合作。

Nvidia 要求 Samsung、SK Hynix、美光三家記憶體廠，NVHBM 的 base die 一律用台積電 3 奈米、核心 die 用第六代 DRAM 技術，目標是讓客製化 HBM 的做法標準化。NVHBM 今年 8 月發表，把原本放在 GPU 上的記憶體控制器搬進 base die，號稱頻寬比標準 HBM4E 高 30%、功耗低 15%。

三星內部評估後接受了 Nvidia 的要求，但標準 HBM 仍維持自家一條龍；若台積電產能不夠，三星也不排除用自家晶圓廠支援。

為什麼重要： 當 AI 晶片的瓶頸從算力轉向記憶體頻寬，連三星都得低頭找死對頭代工——這是 HBM 正式成為「兵家必爭之地」的宣告。

北京點頭了：字節、阿里、騰訊獲准買 40 萬顆 H200

路透報導，中國政府已批准字節跳動、阿里巴巴、騰訊採購 Nvidia H200 晶片，總量超過 40 萬顆；幾乎同時，美國商務部也正式批准 H200 對華出口新規，採個案審批制。

據知情人士，北京要求附帶條件的後續採購也會陸續放行，但另一消息來源稱許可條件嚴苛、未必能轉成實際訂單。美國新規要求：晶片先經第三方實驗室驗證性能、出口量不得超過美國客戶量的一半、中國客戶須證明有足夠資安程序、不得軍用，且維持 25% 出口稅。

此前 1 月北京曾要求暫停 H200 訂單、轉向國產晶片；如今轉為「配額制」務實放行。Nvidia 在最新 10-Q 中坦言已被中國政府「實質排除在資料中心運算市場之外」。

為什麼重要： 美中在 AI 晶片上從「互相封殺」進入「有條件放行」的新階段——配額、稅、資安審查三管齊下，H200 成了科技戰的談判籌碼。
