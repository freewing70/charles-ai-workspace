Architecture Overview

Charles AI Workspace v1.0

無傳統伺服器、可持續擴充的個人 AI 工作、知識與作品管理中心。

  • Static-First 架構：極速載入、零伺服器維護負擔
  • Metadata 驅動：嚴謹 Schema 驗證，平滑升級資料庫
  • Build-time 隱私隔離：私人項目徹底杜絕外洩風險
Content Modules

八大核心體系

涵蓋個人知識管理與創作資產的完整生命週期：

  • Skills：AI 提示詞、系統指令與版本演進
  • Presentations：在線播放 HTML 簡報，手機電腦通讀
  • Projects：實務成果與技術鏈路交叉參照
  • Timeline & Search：毫秒級 Fuse.js 檢索與歷程足跡
Automated Workflow

Codex 自動內容管線

標準化 CLI 與 GitHub Actions CI/CD：

  • 輸入自然語言命令自動加入新資產
  • 自動生成 Slug、驗證 Metadata 與構建搜尋索引
  • 零手動修改多檔之風險，一鍵部署 Cloudflare Pages
