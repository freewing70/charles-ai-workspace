## Chow 的 AI 模型日報｜第 024 號 (2026.10.21)

## 今日五看

1. **OpenAI 搶在 Anthropic 上市前募資 300 億美元**：路透社報導 OpenAI 正加速進行約 300 億美元新一輪募資，目標估值超過 1.4 兆美元，力拚在競爭對手 Anthropic 11 月中旬 IPO 之前鎖定估值定價權。
2. **Anthropic 再談 450 億美元算力大單**：輝達投資之資料中心商 Nscale 正與 Anthropic 談判西維吉尼亞 Monarch 園區二期約 460MW 容量之租約，若簽成雙方累計承諾逼近 900 億美元。
3. **路透獨家：AI 駭客大軍出動攻擊上千網站**：資安專家觀測到駭客以 DeepSeek 與 Claude Code 混合架構透過 Cairn 平台指揮多 Agent，每次僅耗費約 5,000 美元 token 即攻破逾千個電商網站。
4. **美國 DeepSeek 聯邦禁令正式刊登公報**：美國國土安全部正式發布排除令，除要求文職機關移除 DeepSeek 產品外，連帶清查所有使用其蒸餾、微調或訓練資料之第三方軟體。
5. **DeepSeek 開源推理引擎 DeepInfer**：DeepSeek 於 GitHub 以 Apache 2.0 協議釋出支撐 V4.1-Flash 的內部推理引擎，公開單叢集日產 1,550 億 token 與 96% 快取命中率之後端實作。
