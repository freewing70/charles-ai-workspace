# Ink Wuxia Fantasy Skill

A reusable Codex/agent skill for creating prompts in a Chinese ink-wash wuxia and mythic fantasy visual language.

## Best for

- 水墨武俠角色
- 巨大神龍／神話生物
- 仙俠與東方奇幻場景
- 水墨鬥氣與武打特效
- 武俠對決
- 角色設定圖
- Hero frames / storyboard keyframes

## Install

Copy the entire `ink-wuxia-fantasy-skill` folder into the Skills directory used by your agent/Codex environment. Keep `SKILL.md` at the root of the skill folder.

## Typical requests

- 「用水墨武俠 Skill 做一個戴斗笠、拿長棍的俠客。」
- 「保持角色不變，把場景改成巨大神龍隱沒在霧中的東方神話構圖。」
- 「把普通發光鬥氣改成真正的水墨鬥氣。」
- 「幫我做一張水墨武俠電影 Hero Frame。」
- 「做角色四視圖，但保持這套水墨風格。」

## Core rule

This is not a generic 'ink filter'. The scene should be designed from the beginning around ink, mist, negative space, selective detail, and Chinese visual rhythm.
